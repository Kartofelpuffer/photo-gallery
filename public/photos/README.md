# Add photographs here

Place optimized image files in this folder, for example:

- `lake-at-sunset.jpg`
- `workshop-detail.jpg`

Then add a matching entry to `data/photos.json`. The `src` value should begin with `/photos/`.

Recommended: use JPEG or WebP, resize very large originals to a sensible web resolution, and keep each file comfortably below GitHub's 100 MB per-file limit.
